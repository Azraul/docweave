# DocWeave

A static site generator purpose-built for **LLM-friendly knowledge bases**. Takes structured markdown notes with YAML frontmatter and generates:

- **Browsable `.site/` output** — a complete static site anyone can open in a browser
- **`index.json`** — a machine-readable index that LLMs can query directly
- **Auto-generated `_index.md` files** — bottom-up propagation of descriptions through the directory tree
- **Graph addon** — visualize wikilink connections between notes
- **Timeline addon** — chronological view of notes with era dates

## Concepts

- **[[research/projects/docweave/architecture|DocWeave Architecture]]** — DocWeave uses bottom-up index propagation — each directory's _index.md aggregates descriptions from its children
- **[[research/projects/docweave/index-propagation|Index Propagation]]** — Propagated indexes let an LLM navigate the entire knowledge base by reading one _index.md per level — from root to leaf in logarithmic steps
