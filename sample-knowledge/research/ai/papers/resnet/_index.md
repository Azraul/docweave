# Deep Residual Learning (ResNet)

**Kaiming He, Xiangyu Zhang, Shaoqing Ren, Jian Sun, 2015.** Microsoft Research.

Introduced residual learning through identity skip connections, enabling the training of networks with 100+ layers. Won ILSVRC 2015 with a 152-layer network (3.57% top-5 error) — deeper than any previous architecture.

## Concepts

- **[[research/ai/papers/resnet/abstract|Abstract — Deep Residual Learning]]** — Residual learning framework that reformulates layers as learning residual functions with reference to layer inputs
- **[[research/ai/papers/resnet/skip-connections|Skip Connections]]** — Identity shortcuts that skip one or more layers, solving the vanishing gradient problem in deep networks
